## [1.0.0] - 2026-08-20

### Added
- Initial release
- Dual deck DJ mixing system
- Crossfader with auto-mix
- 3-band EQ for each deck
- BPM detection and sync
- Hot cue system
- Pitch control (0.8x - 1.2x)
- Real-time waveform display
- Audio effects:
  - Echo, Reverb, Delay
  - Flanger, Phaser
  - Low-pass/High-pass filters
  - Distortion, Bitcrusher
- X/Y modulation pad
- 32-band spectrum analyzer
- TikTok Live API integration
- RTMP streaming support
- Configurable resolution and bitrate
- Microphone input
- Device music library browser
- Dark theme UI
- Auto-update system via GitHub Releases
- CI/CD with GitHub Actions
